Dexterous Pick-and-Place

A camera finds the object in 6D, a GPU grasp synthesizer plans a multi-finger grasp plus a collision-free arm trajectory, and a UR arm with a 16-DoF Allegro hand picks the object and places it. One synthesis service drives both the Isaac Lab digital twin (both arms) and the real robot.

How it works

01 · perceiveFoundationPoseYOLO-World + SAM 2 + FoundationPose give the object pose in the world frame. In sim the spawn pose is used.
02 · synthesizeBODex on cuRoboHundreds of force-closure grasp seeds are optimized in parallel, with IK for pregrasp, grasp and lift. The other arm is treated as an obstacle.
03 · selectSecure, collision-freeThe chosen grasp engages the most fingers. Open-hand approaches that would hit the arm or table are rejected, and side grasps go up, out, down and in.
04 · executeClosed-loop barriersA 125 Hz joint stream. The hand closes only once the arm has arrived and opens at the place with the arm held still, behind safety gates.

Try it

git clone https://github.com/ismael-esp/dexterous-pick-and-place.git
cd dexterous-pick-and-place
bash scripts/install.sh                      # bodex env + CUDA kernels + Isaac Lab scene assets
python scripts/check_install.py --synth      # one real grasp + trajectory synthesis
ISAAC_PY=/path/to/isaaclab/python bash scripts/run_sim_benchmark.sh   # both arms in Isaac Lab

Tested on Ubuntu 22.04 with 2× RTX 5070 Ti, CUDA 12.8, Isaac Sim 5.1 + Isaac Lab 2.3.0 and ROS 2 Humble. The README covers hardware setup, adding objects, configuration and troubleshooting.
